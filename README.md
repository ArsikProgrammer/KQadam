# KADAM

Навигатор школьной математики: граф тем 5–11 классов, диагностика пробелов до
контрольной, кабинет методиста (сравнение учебников и распределение часов) и
трек от долей до ЕНТ.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Структура

- `src/data` — граф тем программы, учебники со статистикой тестов, блоки ЕНТ
- `src/lib` — модель риска, аналитика учебников, LLM-адаптер (OpenAI-совместимый API)
- `src/components` — секции сайта
- `src/three` — 3D-сцена с книгами (three.js)

## AI-разбор учебника

Панель «AI-разбор учебника» работает с любым OpenAI-совместимым API (OpenAI,
локальный Ollama). Ключ вводится в интерфейсе и хранится только во вкладке.
Без ключа запускается детерминированный локальный расчёт по статистике тестов.
