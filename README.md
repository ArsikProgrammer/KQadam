# KADAM

Навигатор школьной математики: граф тем 5–11 классов с зависимостями,
диагностика пробелов до контрольной и трек от долей до ЕНТ.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Структура

- `src/data` — граф тем программы (43 темы), блоки ЕНТ, контекст реальных
  учебников, сохранённые AI-разборы
- `src/lib` — модель риска, сборка промпта, LLM-адаптер (OpenAI-совместимый API)
- `src/components` — секции сайта
- `src/three` — 3D-сцена с книгами (three.js, грузится лениво)

## Секции

- **Граф знаний** — 43 темы 5–11 классов, связи «опора → зависимость», последствия пробелов
- **Диагностика** — интерактивная модель риска: пробелы в опорах, ошибки, практика
- **Трек к ЕНТ** — опорные узлы программы и блоки экзамена
- **AI-разбор учебников** — разбор реальных изданий моделью Qwen 3.7 Flash

## AI-разбор учебника

Модель разбирает структуру и содержание реального учебника (прочитаны
оригинальные PDF-издания: титульные данные, условные обозначения, содержание,
структура параграфов — см. `src/data/bookContext.ts`) и оценивает по пяти
критериям. Готовые разборы сохранены в `src/data/reports.ts` заранее; кнопка
«Пересчитать моделью» запускает свежий пересчёт.

Ключ API задаётся одним из способов:

1. переменная `VITE_LLM_API_KEY` в `.env.local` (см. `.env.example`);
2. ввод в поле «Ключ API» во вкладке — хранится только в `sessionStorage` и не
   покидает браузер.

Модель настроена экономно (`reasoning_effort: low`, `max_tokens`) — один
пересчёт ≈ 3K токенов. Ключи и секреты в репозиторий не коммитятся.

## Данные

- **Реальные учебники.** В локальной папке `books/` (не коммитится) лежат PDF
  школьных учебников: Алдамуратова Т.А. (Атамұра, 2017) и Абылкасымова А.Е.
  (Мектеп, 2017), 5 класс, по 2 части. Из них извлечён контекст для AI-разбора.
