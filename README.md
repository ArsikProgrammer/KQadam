# KADAM

Навигатор школьной математики: граф тем 5–11 классов, диагностика пробелов до
контрольной, кабинет методиста (сравнение учебников и распределение часов) и
трек от долей до ЕНТ.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Структура

- `src/data` — граф тем программы (43 темы), учебники со статистикой тестов по
  всем темам, блоки ЕНТ, сохранённые AI-разборы
- `src/lib` — модель риска, аналитика учебников, LLM-адаптер (OpenAI-совместимый API)
- `src/components` — секции сайта
- `src/three` — 3D-сцена с книгами (three.js, грузится лениво)

## AI-разбор учебника

Панель «AI-разбор учебника» отправляет модели Qwen 3.7 Flash (OpenAI-совместимый
API `api.commandcode.ai`) результаты тестирования по всем 43 темам программы и
получает структурированный разбор по шести критериям.

Ключ API задаётся одним из способов:

1. переменная `VITE_LLM_API_KEY` в `.env.local` (см. `.env.example`);
2. ввод в поле «Ключ API» во вкладке — хранится только в `sessionStorage` и не
   покидает браузер.

Без ключа панель показывает сохранённые разборы модели из `src/data/reports.ts`.
Ключи и секреты в репозиторий не коммитятся.

## Данные

- **Реальные учебники.** В локальной папке `books/` (не коммитится) лежат PDF
  школьных учебников (Атамұра и Мектеп, 5 класс, 2017). Из них извлечены
  титульные данные, структура глав и методические особенности — они хранятся в
  `src/data/bookContext.ts` и подставляются в промпт AI-разбора, поэтому анализ
  структуры, терминологии и практики опирается на реальные издания.
- **Статистика тестирования** (освоение, ошибки, выборки, часы) —
  демонстрационные данные для прототипа, а не результаты реальных исследований.
  Заменяются на настоящие выгрузки в `src/data/textbooks.ts`.
- Учебник «Нұрлан» недоступен в открытом доступе: его разбор строится только по
  статистике, о чём панель честно предупреждает.
